# Sources, artwork and attribution

The MIT license applies to RefGarden's original application code and documentation. Third-party dependencies keep their own licenses. Images and source descriptions retrieved by the app are not relicensed by this repository.

- [The Met Open Access](https://www.metmuseum.org/hubs/open-access) provides public-domain artwork images and basic collection data under CC0. The adapter requests public-domain objects with images.
- [NASA images and media guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/) describes permitted uses and exceptions, including third-party material, protected marks and endorsement concerns. Preserve each item's credits.
- [Cosmos terms](https://www.cosmos.so/legal/terms-conditions), particularly section 8(F), restrict automated searching and downloading. The public-page adapter is experimental and requires appropriate permission. Open-sourcing its implementation does not grant source access or image reuse rights.
- The sample catalog contains external URLs and attributed source metadata. It is a legacy demonstration catalog, not a bundled image library or a rights-cleared commercial asset pack.

The README cover is original generated concept artwork made for RefGarden. It does not depict an actual search result. Its creation prompt is in [ART.md](docs/ART.md). No retrieved third-party artwork was uploaded as an image-generation input.

The project uses Nunito Sans through Google Fonts; it is distributed by its authors under the [SIL Open Font License](https://github.com/google/fonts/blob/main/ofl/nunitosans/OFL.txt). The app requests the font from Google's servers rather than bundling a local copy.

The examples [Jev Ultrafast](https://github.com/browser-use/jev-ultrafast) and [Jev Trader](https://github.com/jarrodwatts/jev-trader) inspired the experiment. RefGarden is independently implemented. Product and organization names belong to their respective owners.

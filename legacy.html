How assets reach you

Find assets searches The Met, Cosmos and NASA for 100 images across the three sources. The images stream into the gallery as each source responds. Jev then picks one standout per source in a single selection request.

Your prompt

Samples use their displayed search phrases. For a custom brief, Jev first chooses a search phrase for each source from options extracted from your text and a small phrase library. Its choices are shown above the results. This adds one request. Creator search uses no Astra calls or browser screenshot worker.

Fresh search and saved results

Each Find assets action queries the live sources again. Saved results below are local history, labeled with their recorded time. The browser and image providers may cache previously viewed thumbnails. Fast repeat image loads are not evidence of faster model decisions.

What Jev evaluates

Jev receives titles and descriptions, not image pixels. Its picks are suggestions from that metadata. Cosmos generated captions may be inaccurate. Every asset links to its original source.

What the timer measures

The main timer runs from your click through source retrieval and Jev’s selection. It includes any retry. Jev’s smaller clock measures the successful API request. The first-image metric records when a loaded image enters the visible gallery. Thumbnails load independently of the model request.

Connection

A TypeSafe key is stored privately in this project’s local .env file. It is never included in browser storage or exports.

Other views

Search displayed queries runs the editable source phrases without Jev and includes actual Playwright browser captures. Earlier saved Astra runs keep their original records. Neither path is used by Find assets.

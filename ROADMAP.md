# A garden that keeps growing

RefGarden helps creators find and keep useful visual references. The spatial gallery makes discovery inviting; the lasting value should be the references people return to when making something.

The name belongs to that workflow. Jev is the first decision provider, and source integrations can change without renaming the project. Open source keeps the implementation inspectable and allows people to run it with their own accounts.

## Available now

Local Jev query choices and metadata highlights; three source adapters; editable prompts; eight styles; progressive image arrivals; continuous discovery; deduplication; source links; pins; saved searches; JSON exports; keyboard controls and reduced motion. The hosted demonstration performs source search without Jev.

## Next: make selection useful and inspectable

- Compare a keyword-only baseline with Jev query choices on the same saved candidate set. Ask creators which references they would actually use; do not infer relevance from speed.
- Show source retrieval time and model decision time separately, with the selected query and evidence behind each highlight.
- Establish permitted source access. Improve recovery when a source is unavailable and expose source selection without crowding the prompt.
- Keep export records portable and version their format before adding new fields that would break saved work.

Acceptance: a creator can explain where a reference came from, what the model saw and why it appeared. Provider failures preserve the work already collected.

## Then: your own references

Add an explicit folder picker for local photos, then source/model interfaces with documented contracts. Keep local photo processing opt-in and disclose any material sent to an external provider. Image analysis is a separate capability from today's metadata decisions.

Acceptance: users select exactly which files the app can read, can revoke access, and can export their collections. No background scan of a camera roll or home directory.

## Later: convenience people choose to pay for

A managed version could offer accounts, synchronized projects, collaboration and usage allowances, while the local application remains available. Test repeat use and willingness to pay before funding unrestricted hosted model calls. Server-funded provider access requires authentication, enforceable budgets and permitted sources.

These are proposed directions. No hosted subscriptions, team workspaces, camera-roll integration or pixel-based Jev evaluation are included in this release. Dates depend on evidence and maintainer capacity.
